# Совпали — Motion Concept 02

Интерактивная дизайн-концепция для мобильного и десктопного web-приложения знакомства, собранная в MagicPath.

## Живое превью
https://designs.magicpath.ai/v1/happy-bay-6943

## Исходники
- Premium.tsx — UI, управление сценами, анимация показателей, модальное окно.
- Experience.css — адаптивная кинематографическая дизайн-система, интро, типографика, motion.

## Важно
Это **отдельный дизайн-прототип**. В нём демонстрационные анкеты, изображения и показатели. СБП и платёжный процесс не активированы, деньги не списываются. Для настоящего производства потребуется интеграция с существующими Flask-маршрутами /s/p/<token>, SQLite/PostgreSQL backend, авторизацией, согласием на открытие контакта, AI-блоками и эквайрингом.

## При интеграции с существующим проектом
- Не заменять текущее приложение/бот без smoke-тестов.
- Заменить фиксированную демо-анкету и проценты реальными серверными данными.
- Использовать существующие функции score / reasons / pc_astro_copy / pc_num_copy; AI-генерация не подключена к данному макету.
- Удалить внешние демо-фотографии, показывать только согласованные реальные фотографии.
- Соблюдать оплату только после подтверждённого webhook, защищённые персональные ссылки и взаимное согласие.
- Учитывать reduced-motion, доступность и поведение на мобильных устройствах.
- Не выдавать астрологию и нумерологию за научный прогноз.
