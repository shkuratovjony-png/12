# Совпали — исходники отдельного проекта

Это подготовленная копия исходников Telegram-бота «Совпали» без файлов курса «Поехали».

**Важно:** это временная миграционная ветка старого репозитория. Для полной изоляции перенести содержимое ветки в новый **приватный** GitHub-репозиторий `sovpali`. Не клонируйте историю старого публичного репозитория: создайте новый чистый репозиторий и перенесите только содержимое файлов.

## Render
- Текущий боевой адрес: https://one2-1o22.onrender.com/
- Действующий сервис: `srv-dbithnvlk1mc73fmkn0g`
- Runtime: Docker
- Dockerfile: `./Dockerfile` (в новом репозитории в корне)
- Root directory при переключении: пусто (ранее исходники находились в папке `sovpali/`)
- Все реальные переменные оставьте в Render Environment, не переносите их в GitHub.
- Существующую базу `sovpali-db` не пересоздавать и не удалять; данные живых пользователей должны сохраниться.
- Перед переключением источника пройти сборку и проверить здоровье бота, оплату и управление анкетами.
- Без подтверждённого успешного запуска нового источника не отключать старый сервис.

## Разграничение
Оплата «Совпали» остаётся отдельной от курса «Поехали». Никаких исходников или доступов курса в этом репозитории нет.
