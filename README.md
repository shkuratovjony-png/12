# Поехали — самостоятельный проект (подготовлен для миграции)

⚠️ Это ветка старого публичного репозитория, не новый репозиторий. После создания отдельного приватного репозитория `poehali` переносите только файлы — без истории старого репозитория.

## Структура
- `landing/` — продающая доска, аудиозаписи и презентация.
- `checkout/` — Ozon-чекаут и закрытый интерактивный курс (`course.html`).

## Render
- Лидмагнит `srv-dblhr3m1egvs73fbbmj0`: https://poehali-lead-board.onrender.com/; publishPath после миграции: `landing`.
- Чекаут `srv-dblihgrncjis73dv6dkg`: https://poehali-checkout.onrender.com/; build: `cd checkout && pip install -r requirements.txt`; start: `cd checkout && gunicorn -b 0.0.0.0:$PORT -w 2 app:app`.
- Уроки не публикуются статическим сайтом; `checkout/course.html` должен выдаваться только после серверной проверки покупки.
- Доступ к старой публичной демоверсии требуется ограничить перед платными продажами.

Курс и «Совпали» должны иметь независимые базы, Ozon токены и Render Environment. Сейчас платежи курса выключены и DATABASE_URL у Poekhali не задан. Не включать реальные списания до проверки электронной выдачи и чека.
