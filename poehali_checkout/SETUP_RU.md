# Поехали — как включить приём 900 ₽ (для владельца)

Рекламная ссылка: https://poehali-lead-board.onrender.com/
Чекаут: https://poehali-checkout.onrender.com/checkout
Курс после подтверждённой оплаты: https://poehali-checkout.onrender.com/course

Сейчас сервис развёрнут, но **намеренно не списывает деньги**. Для запуска нужны настоящие реквизиты Ozon Pay, постоянная база заказов, электронная выдача доступа и проверенные фискальные чеки.

## 1. Банк
Зайти в Ozon Банк → Эквайринг. Проверить, что магазин (сейчас может называться Digital Skill) имеет право продавать онлайн-курс «Поехали» за 900 ₽. Уточнить, как выставить чек именно за этот цифровой продукт, и включить «Онлайн-чеки».

Создать/получить действующие API credentials на стороне эквайринга: accessKey, secretKey, notification secret. **Не отправлять их в переписку и не добавлять в GitHub!**

Документация: https://docs.ozon.ru/api/acquiring/
Описание интернет-эквайринга: https://finance.ozon.ru/business/acquiring/internet

## 2. Постоянная база данных
На Render уже занята бесплатная PostgreSQL база «sovpali-db». Она заканчивает бесплатный срок 30 ноября 2026 года. Render не позволяет вторую активную бесплатную базу в этом аккаунте. **Нельзя начинать продажи с исчезающей базой заказов и доступов.**

Нужно создать отдельную долговременную PostgreSQL базу (план согласовать до списания денег), затем в настройках новой службы «poehali-checkout» в Render → Environment установить DATABASE_URL. Базу «Совпали» не трогать.

## 3. Среда Render
Открыть https://dashboard.render.com/web/srv-dblihgrncjis73dv6dkg → Environment.
Переменные задавать только там. Действующий SESSION_SECRET уже установлен.

PUBLIC_BASE_URL = https://poehali-checkout.onrender.com
DATABASE_URL = защищённый DSN нового Postgres
OZON_PAY_MODE = live
OZON_PAY_ACCESS_KEY = ID токена из Ozon
OZON_PAY_SECRET_KEY = секрет из Ozon
OZON_PAY_NOTIFICATION_SECRET_KEY = секрет уведомлений из Ozon
SMTP_HOST = SMTP почтового сервиса
SMTP_PORT = 587
SMTP_USER = почтовый ящик для писем покупателям
SMTP_PASSWORD = пароль приложения / SMTP секрет
SMTP_FROM = адрес почтового ящика продавца
SELLER_NAME = реальное название ИП
SELLER_INN = реальный ИНН
SELLER_EMAIL = контакт покупательской поддержки

POEHALI_FISCAL_CONFIRMED = 0 до проверки чеков
POEHALI_LEGAL_CONFIRMED = 0 до публикации настоящей оферты, политики данных и правил возврата
POEHALI_SELLING_ENABLED = 0 до успешных тестов

## 4. Контент и юридические страницы
В исходнике poehali_checkout/app.py сейчас заглушки /terms и /privacy. Заменить на реальные документы с реквизитами и условиями возврата; добавить согласие с обработкой данных. Не включать POEHALI_LEGAL_CONFIRMED до этого.

Сейчас полный курс доступен бесплатно на старом публичном https://poehali-course-preview.onrender.com/ и в публичном GitHub репозитории. Для работающей платной защиты нужно перенести исходники курса в **отдельный приватный репозиторий** и убрать полную публичную демоверсию. Новый /course уже требует подтверждённую покупку, но старые копии всё ещё общедоступны.

## 5. Проверки перед публичным запуском
1. Проверить /health — database=true, checkout_ready=false пока безопасный режим.
2. Создать заказ 900 ₽ в согласованном тестовом окружении Ozon и убедиться в правильном магазине, названии и сумме.
3. Возврат без платежа или поддельная ссылка не должны выдавать доступ.
4. При реальном успешном платеже API банка должен сообщить paid со строгой суммой 90000 коп. и валютой 643.
5. Покупатель получает официальный фискальный чек от Ozon Pay и письмо с персональной ссылкой на курс.
6. Проверить повторное открытие курса из email, ссылку на другом браузере, повторный платёж, отказ, возврат, отзыв доступа.
7. Проверить, что старые публичные страницы не отдают полный текст курса.
8. Только после реальных тестов установить флаги POEHALI_FISCAL_CONFIRMED=1, POEHALI_LEGAL_CONFIRMED=1, POEHALI_SELLING_ENABLED=1 и проверить, что покупка действительно активна.

## 6. Правила Telegram
Рекламный ролик может вести напрямую на самостоятельный сайт с Ozon Pay. Если продавать цифровой курс **из Telegram-бота или Mini App внутри Telegram**, Telegram требует Stars. Нельзя использовать ссылку на внешнюю оплату как обход этого правила. См. https://core.telegram.org/bots/payments-stars

Без банковских секретов, постоянной базы и протестированных чеков подтверждать готовность продажи нельзя.
