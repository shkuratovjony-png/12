# Автоворонка «Поехали» — Telegram

## Что реализовано
- Отдельная воронка по каждому курсу: `funnel_leads`, `funnel_events`, отдельный статус согласия и покупки.
- Старт `/start poehali`: приветствие, 5 шагов бесплатной схемы, презентация и предложение курса.
- Продающая страница сохраняет анонимный `ft` через форму оплаты: `/checkout?funnel=<ref>`. Ref криптографически случайный, Telegram ID не включается в ссылку.
- После подтверждённой оплаты Ozon (а не после клика) запись помечается `purchased`; рекламные сообщения для этого курса прекращаются.
- Четыре сообщения: +4 часа, +24 часа, +72 часа, +6 дней (от начала согласованной серии, ориентировочно).
- Отправка только 10:00–20:00 МСК; /stop или кнопка отключает сообщения немедленно. Нет фиктивной срочности, гарантированного дохода или ложных отзывов.
- При незавершённом платеже серия замораживается и не предлагает повторную оплату, пока банк не подтвердит состояние заказа.
- Пользователь может отметить «Я уже купил» для прекращения прогрева на другом устройстве: это не выдаёт курс без подтверждения банка.
- GitHub Actions запускает защищённый планировщик каждые 30 минут с OIDC-токеном, без платных Cron и общих секретов.

## Одно действие для подключения нового бота
1. Создать отдельного бота в `@BotFather` через `/newbot`. Не использовать токен «Совпали».
2. В сервисе `poehali-checkout` в Render указать `TG_FUNNEL_BOT_TOKEN` со значением нового токена; сохранить. Не отправлять токен в переписку.
3. После деплоя открыть `https://poehali-checkout.onrender.com/funnel/health` — `telegram_configured: true`.
4. Кнопка сайта «Получить бесплатную схему в Telegram» ведёт на `/funnel/start`, который перенаправит на `https://t.me/<bot>?start=poehali`.
5. Нажать Start в Telegram, затем «Получить 4 полезные подсказки». Без такого согласия сообщения по расписанию не идут.

**Почему без шага 1 бот не работает:** Telegram не разрешает ботам писать первым. Первый /start инициирует пользователь; бот-ключ создаётся только через BotFather.

## Техническая схема
- Webhook: `POST /funnel/telegram/webhook`; Telegram `setWebhook` настраивается автоматически при запуске сервиса с токеном. Секрет webhook получается из уже существующего `SESSION_SECRET` и не хранится в GitHub.
- OIDC-планировщик: `.github/workflows/poehali-funnel-dispatch.yml` в default branch `main` (GitHub schedule работает только из default branch). Проверяются RS256, issuer, audience, точный repository, ref и workflow_ref.
- Системная проверка: `GET /funnel/health`.
- Тесты: `python -m unittest discover -v -p 'test_*.py'`.
- В будущем ещё курс добавляется в `PRODUCTS`, без нового проекта в Render или новой общей таблицы платежей. У каждого курса свой product ID и своя цепочка.

## Ограничения и продакшен
- Без BotFather-токена `telegram_configured=false`; вход в бота ещё не активен.
- Покупка должна происходить по ссылке с `funnel`-меткой. Покупки с другого устройства или по прямой ссылке без метки нельзя безопасно автоматически связать с Telegram-аккаунтом по одному email. Для таких покупателей есть кнопка ручной остановки.
- GitHub Actions не гарантирует отправку в точную минуту, а бесплатный Render может просыпаться после простоя.
- В настоящий момент ошибку Ozon `createOrder HTTP 500 / code 13` требуется устранить отдельно. Без подтверждения банка воронка не должна фиксировать продажу и открывать доступ.
- Бесплатная БД Render имеет срок жизни — её нужно сохранить или перенести до истечения периода бесплатного использования.
